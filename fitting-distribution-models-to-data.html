Chapter 3 Fitting Distribution Models to Data

3.1 Overview of Common Distribution Models

3.1.1 Discrete Distributions

Distribution What it models Notation Parameters PMF \(P(X=x)\) Expectation \(E[X]\) Variance \(\mathrm{Var}(X)\)
Discrete Uniform Finite set of equally likely outcomes \(X \sim \mathrm{DU}(a,b)\) \(a,b \in \mathbb{Z}, a \le b\) \(P(X=x)=\frac{1}{b-a+1}\) for \(x=a,\dots,b\) \(\frac{a+b}{2}\) \(\frac{(b-a+1)^2-1}{12}\)
Bernoulli Single trial with success/failure outcome \(X \sim \mathrm{Bernoulli}(p)\) \(0 \le p \le 1\) \(P(X=x)=p^x(1-p)^{1-x}\), \(x\in\{0,1\}\) \(p\) \(p(1-p)\)
Binomial Number of successes in \(n\) independent Bernoulli trials \(X \sim \mathrm{Bin}(n,p)\) \(n\in\mathbb{N},\ 0\le p\le1\) \(P(X=x)=\binom{n}{x}p^x(1-p)^{n-x}\) \(np\) \(np(1-p)\)
Geometric Number of trials until first success \(X \sim \mathrm{Geom}(p)\) \(0 < p \le 1\) \(P(X=x)=(1-p)^{x-1}p,\ x=1,2,\dots\) \(\frac{1}{p}\) \(\frac{1-p}{p^2}\)
Poisson Number of events occurring in a fixed interval \(X \sim \mathrm{Pois}(\lambda)\) \(\lambda>0\) \(P(X=x)=\frac{\lambda^x e^{-\lambda}}{x!}\) \(\lambda\) \(\lambda\)

3.1.2 Continuous Distributions

Distribution What it models Notation Parameters PDF \(f(x)\) CDF \(F(x)\) Expectation \(E[X]\) Variance \(\mathrm{Var}(X)\)
Normal Symmetric continuous data around a mean \(X \sim \mathcal{N}(\mu,\sigma^2)\) \(\mu\in\mathbb{R},\ \sigma>0\) \(f(x)=\frac{1}{\sqrt{2\pi\sigma^2}}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)\) \(F(x)=\Phi\left(\frac{x-\mu}{\sigma}\right)\) \(\mu\) \(\sigma^2\)
Standard Normal Standardized normal variable \(X \sim \mathcal{N}(0,1)\) none \(f(x)=\frac{1}{\sqrt{2\pi}}e^{-x^2/2}\) \(F(x)=\Phi(x)\) \(0\) \(1\)
Exponential Waiting time between Poisson events \(X \sim \mathrm{Exp}(\lambda)\) \(\lambda>0\) \(f(x)=\lambda e^{-\lambda x},\ x\ge0\) \(F(x)=1-e^{-\lambda x}\) \(\frac{1}{\lambda}\) \(\frac{1}{\lambda^2}\)
Continuous Uniform All values in an interval equally likely \(X \sim U(a,b)\) \(a<b\) \(f(x)=\frac{1}{b-a},\ a\le x\le b\) \(F(x)=\frac{x-a}{b-a}\) \(\frac{a+b}{2}\) \(\frac{(b-a)^2}{12}\)
Triangular Data with minimum, maximum, and most likely value \(X \sim \mathrm{Tri}(a,c,b)\) \(a<c<b\) \(f(x)=\begin{cases}\frac{2(x-a)}{(b-a)(c-a)}, & a\le x<c \\[6pt]\frac{2(b-x)}{(b-a)(b-c)}, & c\le x\le b\end{cases}\) \(F(x)=\begin{cases}0, & x<a \\[4pt]\frac{(x-a)^2}{(b-a)(c-a)}, & a\le x<c \\[6pt]1-\frac{(b-x)^2}{(b-a)(b-c)}, & c\le x\le b \\[6pt]1, & x>b\end{cases}\) \(\frac{a+b+c}{3}\) \(\frac{a^2+b^2+c^2-ab-ac-bc}{18}\)
